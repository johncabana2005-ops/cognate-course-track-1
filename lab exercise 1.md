Arduino Uno R3 is among the most widely used microcontroller boards. Arduino Uno R3 is based on the ATmega328P microcontroller. It is used for reading sensors and other input and sending the output to actuators. In addition, Arduino Uno R3 can read inputs, such as sensors, button inputs, or data from other devices. This board is commonly used in schools because of its easy design and user-friendly software.

Hardware Features
This board has 14 digital pins (with six pins supporting Pulse Width Modulation feature) and six analog pins. It works under 5 volts. Moreover, it may be powered via a USB port or an external power source. In turn, a USB port enables downloading program codes from a computer using the Arduino IDE software. Arduino supports programming language based on C and C++.

Advantages
One of the main benefits associated with using Arduino Uno R3 is the open-source characteristic. All users can get access to its schematics, libraries, and other information via Internet resources. Such strong community support allows beginners to solve any problem quickly.
